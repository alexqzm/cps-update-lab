# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/). До 1.0 форматы стенда и интерфейс командной строки

## [0.2.0] — 2026-11-18

### Добавлено
- Канал рецептов партии от ИИ-агента: формат `cpslab-recipe/1`, статическая проверка против программы
  контроллера по принципу «запрещено всё, что не разрешено», исполнение на контроллере, пробный прогон на
  двойнике объекта с условиями приёмки из технологического задания (`cpslab/recipe.py`).
- Сервер агента: ключи уровней Read, Recipe и Manual, потолки уровня на всё развёртывание, режим управления
  local/remote (переключает оператор), папка рецептов ключа, неизменяемые ревизии, журнал с хеш-цепочкой,
  аттестация авторства in-toto с материалами сеанса (`cpslab/agent_server.py`, `cpslab/journal.py`).
- Мост MCP `cpslab mcp` (stdio, JSON-RPC 2.0, рукопожатие initialize версий 2024-11-05 … 2025-11-25,
  запрос server/discover отклоняется для перехода клиента к рукопожатию); проверен официальным клиентом MCP 2.3.0.
- Гейт рецептов: профиль scii-gate с десятью свидетельствами q11–q52, порог θ = 0,8 по эталонному рецепту,
  VSA, квитанция SCII-R v1 с привязкой к дайджесту рецепта, экземпляру устройства, политике допуска рецептов
  и ревизии; контроллер проверяет её тем же scii-agent (`cpslab/recipe_gate.py`).
- Подписанные документы ролей технолога, метролога, оператора и инженера по безопасности
  (`cpslab/documents.py`); ключи этих ролей и сервера агента.
- 10 сценариев канала рецептов (RN1, RA1–RA7, RM1, RM2) × 3 уровня = 30 исходов, сверка в CI,
  `docs/results-recipes.md`, `docs/agent-recipes.md`, ЛР-8.
- Живой стенд: служба `agent-server` (порт 8026), `./lab.sh recipes | mode | approve | journal`,
  `cpslab live recipe-demo`, подключение Claude Code к мосту MCP.
- Монитор сверяет исполненные рецепты с журналом допусков гейта рецептов и выводит ручные команды агента.

### Изменено
- Контроллер: ручной режим насоса (от рецепта или команды), блокировки ПАЗ сохраняют приоритет; новые точки
  API контроллера `/api/program`, `/api/recipe`, `/api/recipe/run`, `/api/recipe/abort`, `/api/command`.
- Пояснения кодов отказа `SIZE`, `DIGEST` и `ROLLBACK` относятся и к рецептам.

## [0.1.0] — 2026-11-06

Первая публикация (выпуск на GitHub не создавался).

### Добавлено
- Поставщик: git-репозиторий с подписанными коммитами и тегами, детерминированная сборка образа,
  аттестации in-toto (cosign) по ролям, журнал хранилища, подписи пакета и загрузчика.
- Гейт: scii-gate с профилем стенда, проверки стадии устройства s51–s53, SLSA VSA в DSSE,
  квитанция SCII-R v1, журнал допусков.
- Контроллер: уровни защиты L0–L2 (scii-agent из scii-verify), пути обновления, инженерной
  станции и управления, модель резервуара, Modbus/TCP, подписанные отчёты, HTTP API; HMI и монитор.
- 11 сценариев (N1, A1–A7, A3b, M1, M2) с ожидаемыми исходами, записями атласа, техниками ATT&CK v20
  и мерами ОПО; таблица результатов, сверяемая в CI.
- Образ Docker с закреплёнными версиями, `compose.yaml` и `lab.sh` для живого стенда.
- Семь лабораторных работ и методические указания для преподавателя.
