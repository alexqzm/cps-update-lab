# Исходный код учебного поставщика

Из этого каталога стенд создаёт git-репозиторий вымышленного поставщика ПО контроллеров.
История выпусков задаётся в `cpslab/vendor.py` (HISTORY): каждый коммит кладёт в
`products/<изделие>/` описание изделия и программу нужной версии из `history/`.

| Изделие | Класс устройства | Выпуски |
|---|---|---|
| Контроллер резервуара ТК-1 (`tank-controller`) | 7001 | 1.0.0 — уставки high и hh записываются по Modbus без ограничений; 1.1.0 — ограничения добавлены; 1.2.0 — скрытая функция «сервисного режима» (сценарий M1) |
| Контроллер насосной станции НС-2 (`pump-station`) | 7002 | 1.1.0 |

Поставщик и изделия вымышлены.
